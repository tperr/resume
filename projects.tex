\section*{Projects}
\textbf{Illuminated Devices} - \textit{React.js, Flask, MariaDB, SocketIO}\\
\textit{Objective:} Create a digital portal for remote digital assistance
\textit{\url{https://github.com/tperr/illuminated-devices}}
\begin{itemize}
    \item Patrons go to the local library to check out device, join a waiting queue when ready, then once a Tutor is ready they are connected for assistance
    \item Implemented the Zoom API to connect Patrons to the Tutors
    \item Two publications resulted from this work
\end{itemize}

\textbf{Brightness Lowerer} - \textit{Python, Bash}\\
\textit{Objective:} Make a tool that lowers brightness when rapid luminosity changes occur \\
\textit{\url{https://github.com/tperr/brightness_lowerer}}
\begin{itemize}
    \item Grabs image of the screen, goes pixel by pixel to calculate the average luminosity
    \item Keeps average luminosity to a relatively consistent range
    \item Mostly a gimmick project, but fun and random idea
\end{itemize}

\textbf{OpenFinAL} - \textit{React.js}\\
\textit{Objective:} Create an open source financial analytics tool \\
\textit{\url{https://github.com/jeffreywallphd/OpenFinAL}}
\begin{itemize}
    \item Programmed as coursework for BA5200 Information Systems Management with React.js, designed with Figma,
    \item An open source financial analytics tool designed to provide financial analytics capabilities at a low cost.
    \item It aims to help users understand their financial situation better and make informed decisions.
    \item My main focus was in the risk management module, which provides users with insights into the risk associated with their investments.
\end{itemize}
