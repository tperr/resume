\section*{Projects}
\textbf{Illuminated Devices}\\
\textit{Objective:} Create a digital portal for remote digital assistance
\begin{itemize}
    \item Patrons go to the local library to check out device, join a waiting queue when ready, then once a Tutor is ready they are connected for assistance
    \item Front end work done using React.js
    \item Back end work done using the python Flask framework utilizing a MariaDB database and SocketIO sockets
    \item Implemented the Zoom API to connect Patrons to the Tutors
    \item Two publications resulted from this work
    \item \url{https://github.com/tperr/illuminated-devices}
\end{itemize}

\textbf{Brightness Lowerer}\\
\textit{Objective:} Make a tool that lowers brightness when rapid luminosity changes occur
\begin{itemize}
    \item Programmed in python, interacting with the linux file system
    \item Grabs image of the screen, goes pixel by pixel to calculate the average luminosity
    \item If over an upper bound lower brightness, if less than lower bound raise brightness
    \item \url{https://github.com/tperr/brightness_lowerer}
\end{itemize}
